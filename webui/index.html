Configuración

Las API keys y los modelos. Se guardan en tu .env (fuera de la carpeta del código). Los secretos se muestran enmascarados; dejalos en blanco para conservarlos.

🔌 Conectores

Servicios que los agentes pueden usar como herramientas. Cargá las credenciales de cada uno en los campos de arriba y Guardá; después tocá Probar. Un conector configurado se enciende solo: sus herramientas aparecen para el agente. Las acciones que escriben (crear, actualizar, mandar) te piden confirmación.

Distribuir

Armá un paquete para compartir. Antes de generarlo revisa que no viajen credenciales; si encuentra algo, no lo arma.

Comprimir conversaciones viejas

Empaqueta las conversaciones más viejas que los días indicados en un .tar.xz (queda en _archivo/ como respaldo) y las saca de la lista. Usa xz/LZMA, que comprime bastante más que el zip de antes. No se pierde nada: solo libera espacio y despeja la lista.

🔒 Secretos para los agentes

Credenciales (tokens, API keys) que los agentes pueden usar sin verlas: se guardan cifradas y el agente las referencia por nombre con {{secreto:ETIQUETA}}. El valor nunca llega al modelo; cada uso te pide confirmación. El agente también puede pedir una credencial nueva y se te abre una ventana.

Enjambres

🧠 Orquestador en dos fases. Escribí una tarea y dale Planificar: el orquestador propone un plan (o te pregunta), lo ajustás, y recién al Ejecutar corren los workers. El enjambre se ve acá como un árbol: desplegá el run para ver el orquestador y sus workers.

🕒 Tareas programadas

Corren solas por el planificador del sistema, con la app cerrada. Las crea el agente desde el chat ("programá una tarea que…"). Acá las ves, las corrés a mano, las recargás o las borrás.

🦊 Captura de tráfico

Abrí un Firefox con un perfil aparte que pasa por el proxy. Todo lo que navegues ahí queda capturado para que el agente lo use. Tu Firefox de todos los días no se toca.
