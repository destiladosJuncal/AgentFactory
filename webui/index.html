Configuración

Las API keys y los modelos. Se guardan en tu .env (fuera de la carpeta del código). Los secretos se muestran enmascarados; dejalos en blanco para conservarlos.

Distribuir

Armá un paquete para compartir. Antes de generarlo revisa que no viajen credenciales; si encuentra algo, no lo arma.

Escribí una tarea y dale a Iniciar. Los agentes colaboran acá; vos también podés escribir (usá @Nombre para hablarle a uno solo).

🕒 Tareas programadas

Corren solas por el planificador del sistema, con la app cerrada. Las crea el agente desde el chat ("programá una tarea que…"). Acá las ves, las corrés a mano, las recargás o las borrás.

🦊 Captura de tráfico

Abrí un Firefox con un perfil aparte que pasa por el proxy. Todo lo que navegues ahí queda capturado para que el agente lo use. Tu Firefox de todos los días no se toca.

URLs capturadas

Agrupadas por dominio. Tocá un dominio para ver sus URLs.
